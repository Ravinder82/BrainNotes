4 What changed
  • Captain card — flat grey slab → raised 20pt card, deep-teal helm disc with halo, teal role line, real press state.
  • Crew cards — tint-noise borders → neutral hairline + soft lift; identity first, status pill second, stack rings that match the card.
  • Section labels — ad-hoc 10.5px/1.2 tracking → one overline token (11/600/+0.08em) with an inline glyph.
  • Icon language — 14 different bare glyph sizes → two disc sizes (44 hero, 36 quiet) and three text sizes.
  • Composer — flat field on a grey strip → hairline pill field floating on a raised bar, focused state gets an accent ring.
  • Send / attach — coloured glyphs floating loose → filled deep-teal send disc (AA) + attach in a quiet disc.
  • Reply strip — flat grey row → bordered card with a deep-teal rail and clipped preview.
  • Bubbles — 8pt corners clashing with the 18pt composer → 14pt family, tail keeps sender side, meta text to AA.
  • Crew manifest card — accent wash + accent stroke + misaligned 46pt dividers → clean surface, accent lives only in the header glyph, dividers align to text at 52pt.
  • White-on-teal — accent #00A884 behind white text (3.03:1, fails WCAG) → deep teal #008069 (4.89:1) everywhere text sits on teal.
  • Corners — scattered 8/12/16/18 → four-step family: 8 / 14 / 20 / pill, nested containers share it.
  • Dark mode — depth by shadow that never renders → depth by hairline #2A3942, no shadows or blur.
